Este repositório é usado para registrar meus estudos em redes de computadores,
com foco em fundamentos de segurança da informação.

Conteúdos:
- Conceitos básicos de redes
- LAN, WAN e SAN
- Internet, Intranet e Extranet
- VPN (conceitos básicos)
- TCP/IP
- Endereçamento IP, máscara de rede e DNS
- Portas e protocolos
- HTTP e HTTPS
- Noções básicas de firewall
- Prática com comandos de rede (ipconfig, ping, tracert)
