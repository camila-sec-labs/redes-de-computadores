# Redes de Computadores - Camila Labs

Este repositório é usado para registrar meus estudos em redes de computadores, com foco em fundamentos de segurança da informação.

Conteúdos:
- Conceitos básicos de redes
- TCP/IP
- Comunicação entre dispositivos
- IP (IPv4), máscara de rede e gateway
- DNS e resolução de nomes
- Redes locais (LAN) e acesso à Internet
- Noções iniciais de segurança em redes
